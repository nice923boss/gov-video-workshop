# 公務短影音工作台

「公務影音簡易剪輯研習班」結尾工作坊用的引導填寫網站。五個階段（企劃五格、分鏡腳本、拍攝清單、AI 補圖與字卡配音、剪輯與多平台輸出）帶你把自己單位的一則公文或活動，企劃成一支公務短影音，每階段由規則檢查，最後產出「公務短影音企劃與製作報告」，可下載 PDF 或寄給老師。

- 網站：https://nice923boss.github.io/gov-video-workshop/
- 填寫的資料只存在你自己的瀏覽器（localStorage），換電腦前請先「匯出進度」，到新電腦按「匯入進度」。PDF 是交件用的報告，不能匯回工作台。
- 診斷由固定規則產生，不是 AI 聊天機器人。
- 範例中的單位與人物是虛構的（青峰市）；請填去識別化資料，不要放民眾個資。
